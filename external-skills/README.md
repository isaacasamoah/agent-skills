# Skills imported from other authors

Keep imported skills byte-for-byte identical to their pinned upstream source. Each directory includes its upstream license and a provenance record with the source revision and content hash. Imported source remains in a fixed local release. Where Isaac approves a local adaptation, home discovery points to its entry in `skills/`, which reads the preserved original.

The Osmani catalog validators enforce Osmani-specific sections, trigger wording and frontmatter. Imported skills retain their authors’ formats and invocation settings. Validate their source hashes, frontmatter, local references, license and installed discovery links separately. Do not alter the catalog validators to make an import pass or describe catalog checks as coverage of these imports.

## Unslop

Lauren Tan’s pstack prose-editing skill is imported from `cursor/plugins`. See [the original skill](unslop/SKILL.md), [provenance](unslop/UPSTREAM.json) and [license](unslop/LICENSE).

The pinned original retains `disable-model-invocation: true`. On 22 October 2026 Isaac approved a [local Unslop entry](../skills/unslop/SKILL.md) for proactive drafting and reactive editing alongside the developer writing guidelines. Home discovery exposes that entry, with automatic selection allowed and explicit invocation available. It reads the original rules and adds readable PR and commit links for human-facing prose.

The 22 October 2026 import is byte-identical to the upstream revision cited by the prior Workshop writing-guidelines draft. The comparison led to adopting Unslop as a second writing check, not a claim that one approach was proved superior.
