# Skills imported from other authors

Keep imported skills byte-for-byte identical to their pinned upstream source. Each directory includes its upstream license and a provenance record with the source revision and content hash. Home discovery links point to these directories in a fixed local release, alongside the catalog in `skills/`.

The Osmani catalog validators enforce Osmani-specific sections, trigger wording and frontmatter. Imported skills retain their authors’ formats and invocation settings. Validate their source hashes, frontmatter, local references, license and installed discovery links separately. Do not alter the catalog validators to make an import pass or describe catalog checks as coverage of these imports.
